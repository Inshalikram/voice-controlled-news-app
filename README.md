# 🎙️ Voice-Controlled News Application

An AI-powered web application that allows users to search, filter, and read the latest news using voice commands. The project is split into a frontend React client and a backend Python server.

---

## 🚀 Key Features
* **Voice Automation:** Hands-free navigation and news filtering via voice controls.
* **Real-time News:** Fetches up-to-date global news headlines and articles.
* **Responsive UI:** Clean, responsive, and fully optimized layout built with React.

---

## 📁 Project Structure
```text
voice-control-newsapp/
├── client/      # Frontend React application (React.js, JSX, CSS)
└── server/      # Backend API environment (Python, Flask/FastAPI)
```

---

## 🛠️ Tech Stack
* **Frontend:** React.js (JSX), CSS3
* **Backend:** Python (`app.py`)
* **Package Managers:** npm (for React), pip (for Python)

---

## 💻 Getting Started

Follow these steps to set up and run the project locally on your machine.

---

### 1. Frontend Setup (React Client)

Navigate to the client directory, install the required node modules, and start the development server:
```bash
cd client
npm install
npm start
```
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

---

### 2. Backend Setup (Python Server)

Navigate to the server directory, install the required python libraries, and run the backend script:
```bash
cd ../server
pip install -r requirement.txt
python app.py
```
